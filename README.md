# Medicine Dispenser

## Overview
This project is an embedded solution designed to prevent misuse of medication among people like children in medically underserved environments.

The system recommends appropriate medicine based on symptoms and provides dosage guidance.

---

## Key Features
- Symptom-based medicine recommendation
- Personalized dosage guidance (age & gender)
- Prescription medication scheduling (morning/lunch/dinner)
- Barcode-based medicine refill system
- Raspberry Pi + touchscreen GUI

---

## System Components
- Raspberry Pi
- Touchscreen GUI (Python)
- Servo motors & LEDs
- Barcode scanner
